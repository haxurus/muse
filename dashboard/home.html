Funzioni

Più vocali, un solo pannello.

Ogni bot è un account Discord separato con la propria coda. La dashboard li tiene insieme senza mescolarli.

Cinque bot

Cinque vocali insieme

Cinque account bot distinti, ognuno nel proprio container isolato. Nello stesso server possono suonare fino a cinque canali vocali contemporaneamente.

Comandi

Slash command per ogni bot

Scegli il bot nell’elenco dei comandi di Discord e usa /play, /pause, /resume, /skip, /queue, /volume, /stop, /disconnect e gli altri.

Dashboard

Accesso con Discord

Vedi solo i server che amministri: proprietario, Amministratore o Gestisci server. I permessi vengono ricontrollati a ogni modifica.

Gruppi

Uno, alcuni o un gruppo

Configura un bot alla volta, una selezione multipla o gruppi salvati per server, come Principali = 1+2+3 ed Eventi = 4+5. I gruppi possono sovrapporsi.

Impostazioni

Ogni bot come vuoi

Volume predefinito, limite playlist, uscita quando il canale resta vuoto, attesa a fine coda, annuncio del brano successivo, volume ridotto quando si parla, pagina della coda e risposte private.

Sorgenti

YouTube, Spotify, SoundCloud

Ricerca, link e playlist YouTube. Link Spotify convertiti in brani YouTube. Link SoundCloud. L’audio già scaricato resta in una cache locale.

Come funziona

Dall’invito alla vocale, in quattro passi.

  1. 01

    Invita i bot

    Ogni bot ha il proprio invito. Aggiungi al server solo quelli che ti servono.

  2. 02

    Accedi con Discord

    La dashboard mostra i server che amministri e i bot presenti in ciascuno.

  3. 03

    Configura per server o per gruppi

    Applica le impostazioni a un bot, a una selezione o a un gruppo salvato.

  4. 04

    Usa /play nella vocale

    Entra in un canale vocale e lancia /play sul bot che vuoi. Un bot per canale.

Self-hosted

Sul tuo server, con le tue regole.

Muse è un fork open source di museofficial/muse, rilasciato con licenza MIT. Il codice è su GitHub.

  1. 01

    Crea cinque applicazioni Discord

    Una per bot. Ogni bot ha il proprio token e la propria cartella dati.

  2. 02

    Prepara i segreti

    Token e credenziali vengono letti da Docker secret montati in /run/secrets.

  3. 03

    Avvia con Docker Compose

    Bot, orchestratore e dashboard partono da un’immagine fissata per digest. Metti la dashboard dietro il tuo reverse proxy.

Sicurezza

Isolati per progetto.

Un music bot non ha bisogno di moderare né di essere raggiungibile da Internet. Muse chiede il minimo e separa tutto il resto.

Un token per bot
Ogni bot ha il proprio token Discord e i propri dati. Un bot non vede i segreti degli altri.
Container blindati
Utente non root, filesystem in sola lettura, nessuna capability Linux, nessun accesso al socket Docker.
Nessuna porta pubblica
I bot non espongono porte. La dashboard è raggiungibile solo tramite un edge proxy che non conosce alcun segreto.
Token OAuth lato server
Il token Discord dell’accesso resta nel processo della dashboard e non arriva mai al browser. Ogni modifica passa controlli CSRF e Origin.
Permessi minimi
Visualizza canali, Invia messaggi, Incorpora link, Leggi la cronologia, Connetti, Parla. Nessun permesso di moderazione.

Più vocali, nessun compromesso.

Aggiungi i bot, accedi con Discord e configura il primo server in pochi minuti.
